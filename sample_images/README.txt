FOLDER CITRA CONTOH
===================
- uji_sintetis_512.png : citra buatan program (BUKAN Mandrill), hanya contoh bawaan.

Untuk memakai citra MANDRILL (baboon):
  1. Unduh citra Mandrill (USC-SIPI Image Database, file 4.2.03, ukuran 512x512)
     atau dari sumber yang diizinkan dosen.
  2. Simpan di folder ini dengan nama:  mandrill.png
     (format .png / .jpg / .jpeg / .tif / .bmp juga dikenali; nama harus diawali "mandrill").
  3. Jalankan ulang aplikasi. Pilihan "Citra Mandrill" akan muncul otomatis di tab
     Enkripsi & Dekripsi.

Catatan: citra ini hanya objek pengujian enkripsi, BUKAN dataset pelatihan GAN.
